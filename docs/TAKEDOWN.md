# Correction and Takedown Process

PustakaTerbuka aggregates publicly available bibliographic metadata. We take data accuracy and rights seriously.

## Corrections

If you find an error in a bibliographic record:

1. Open an issue at https://github.com/aplikasi-perpustakaan/pustaka-terbuka/issues with the record ID and a description of the error.
2. For bulk corrections, submit a pull request against the relevant files in `data/`.

## Takedown Requests

If you believe any record or data in this repository should be removed:

1. Open an issue or email the repository maintainers (see CODEOWNERS).
2. Include: the specific record(s), the reason for removal, and your relationship to the data.
3. We will respond within 7 business days and remove contested records promptly while the request is reviewed.

## Scope

PustakaTerbuka contains only bibliographic metadata (titles, authors, publishers, classifications, identifiers). It does not contain full-text content, circulation data, or personal information beyond cataloger attributions already present in MARC records.
